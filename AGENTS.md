# AGENTS.md — инструкции для ИИ-агентов

Репозиторий `macbook_setup` — скрипты первичной настройки MacBook (macOS, Apple Silicon).
Ручные шаги и пользовательская документация — в `README.md`.

## Как устроен проект

- `main.sh` — точка входа: последовательно запускает шаги из массива `STEPS`, весь вывод дублируется через `tee` в `setup_log.txt`.
- `NN_name.sh` — нумерованные шаги (01–10). Новый шаг = новый файл со следующим номером + строка в `STEPS` в `main.sh`.
- `lib/common.sh` — общие хелперы: `log_ok/log_info/log_warn/log_err`, `ensure_line_in_file`, `find_goland_dir`, `require_brew`. Подключение: `source "$(cd "$(dirname "$0")" && pwd)/lib/common.sh"`.
- `10_cmds.sh` — генерирует персональный CLI-хелпер `~/.local/bin/c` (подкоманды: `help`, `tlog`, `klogin`, `kpods`, `kfw`, `klogs`, `krestart`, `vget`, `vren`, `vtok`).

## Конвенции

1. Bash, в каждом скрипте: `set -euo pipefail`.
2. Скрипты простые и линейные: минимум обёрток и хелперов-абстракций. Константы (например VPN IP) хардкодятся в скрипте — отдельных конфигов нет.
3. Идемпотентность: повторный запуск любого шага безопасен. Правки конфигов — только через `ensure_line_in_file`.
4. Документация и ручные шаги живут в `README.md` — единый источник; скрипты могут читать и печатать текст оттуда.
5. Стиль вывода: `→` начало действия, `✔` успех, `⏭` уже настроено, `❌` ошибка (через хелперы из `lib/common.sh`).
6. Сообщения скриптов и комментарии — на русском.

## Проверка изменений

- Синтаксис: `bash -n <script>.sh`
- Шаги, меняющие `$HOME`, тестировать с временным HOME:
  ```bash
  TMP_HOME="$(mktemp -d)"; HOME="$TMP_HOME" bash 10_cmds.sh
  ```
- Полный `main.sh` на реальной машине запускать только по явной просьбе пользователя.

## Git

- Сообщения коммитов: коротко, на английском, повелительное наклонение (`Add ...`, `Fix ...`).
